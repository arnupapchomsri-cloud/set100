# SET Daily Scanner — คู่มือติดตั้งและตั้งค่าให้รันอัตโนมัติทุกวัน

## 1) ติดตั้ง (ทำครั้งเดียว)
```bash
pip install yfinance pandas
```
(บน Linux บางเครื่องอาจต้องเติม `--break-system-packages` ต่อท้าย)

## 2) ทดสอบรันครั้งแรก
```bash
python3 set_daily_scan.py
```
จะเห็น Top 20 Gainers, Top 20 Losers, และรายชื่อหุ้นที่เข้าเงื่อนไข BUY/SELL พิมพ์ออกทางหน้าจอ
พร้อมเซฟไฟล์ผลลัพธ์เต็มไว้ที่ `set_scan_output/set_scan_YYYY-MM-DD.csv`

## 3) แก้ไขรายชื่อหุ้นที่ต้องการสแกน
เปิดไฟล์ `set_daily_scan.py` แก้ list ชื่อ `TICKERS` ด้านบนไฟล์ — ใส่/ลบ symbol ได้ตามต้องการ
(ค่าเริ่มต้นคือ SET100 ตามประกาศล่าสุดที่มีตอนเขียนสคริปต์นี้ — ครอบคลุมหุ้นใหญ่/สภาพคล่องสูงสุด ~100 ตัว
ซึ่งคิดเป็นสัดส่วนมูลค่าซื้อขายส่วนใหญ่ของตลาดจริงๆ ตัวหุ้นในดัชนีจริงมีการทบทวนทุก 6 เดือน
ควรเช็คกับ set.or.th เป็นระยะว่ารายชื่อยังตรงอยู่ไหม)

## 4) ตั้งให้รันอัตโนมัติทุกวัน

### macOS / Linux (cron)
```bash
crontab -e
```
เพิ่มบรรทัดนี้ (รันทุกวันจันทร์-ศุกร์ 17:00 น. หลังตลาดปิด):
```
0 17 * * 1-5 cd /path/to/thai-stock-dashboard && /usr/bin/python3 set_daily_scan.py >> scan.log 2>&1
```
แก้ `/path/to/thai-stock-dashboard` เป็น path จริงที่คุณเก็บไฟล์ไว้

### Windows (Task Scheduler)
1. เปิด **Task Scheduler** → Create Basic Task
2. ตั้งชื่องาน เช่น "SET Daily Scan"
3. Trigger: Daily, เวลา 17:00
4. Action: Start a program → Program: `python`, Arguments: `set_daily_scan.py`,
   Start in: (path โฟลเดอร์ที่เก็บไฟล์นี้)

## 5) รับสรุปผ่านไลน์/อีเมลทุกวัน (ทางเลือกเสริม)
ถ้าอยากได้สรุปส่งเข้า LINE Notify หรืออีเมลอัตโนมัติแทนการเปิดดู log เอง
บอกผมได้เลย ผมช่วยต่อโค้ดส่วนนั้นเพิ่มให้ได้

---
⚠️ **หมายเหตุสำคัญ:** สัญญาณ BUY/SELL ในสคริปต์นี้เป็นผลจากกฎเชิงเทคนิค (SMA crossover, RSI, MACD)
ที่ตั้งไว้ตายตัวเท่านั้น ไม่ใช่คำแนะนำการลงทุนจากผู้เชี่ยวชาญ และไม่ได้พิจารณาข่าว งบการเงิน หรือปัจจัยพื้นฐานใดๆ
ใช้เป็นข้อมูลประกอบการตัดสินใจของคุณเอง ไม่ควรใช้เป็นคำตอบสำเร็จรูปในการซื้อขายจริง
